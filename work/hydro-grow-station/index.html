Asset & interface

Upgrade Station

The base station plus three independent same-tier upgrades, each modifying a different system with its own visual identity. The skeleton stays the same throughout — dish, control unit, grow bed — so all four read as one machine family at a glance. Construction logic drives every component: the water chain (rain catcher → tank → valve → sprinklers) and the power loop are traceable by eye. The purchase interface is built around that set — a variant carousel, with resource costs pulled from parts visible in the concepts.
